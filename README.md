# Vamos adicionar Funcionalidades dinâmicas no nosso jogo da Velha
Features sugeridas:
Fazer no mínimo uma dessas: 

Placar & “melhor de 3”

Estados: scoreX, scoreO, round, bestOf=3.

Ao detectar vencedor/empate, incrementa placar, bloqueia jogadas e mostra botão “Próxima rodada” (reinicia tabuleiro mantendo o placar).

Série termina quando alguém atinge 2 vitórias.

Bot “Fácil” (single-player)

Toggle “vs Bot”. Quando for a vez do bot, escolha um espaço vazio aleatório após um setTimeout curto (simula “pensando”).

Timer por jogada (10s)

Cronômetro regressivo; se zerar, passa o turno ou executa jogada automática (em “vs Bot”).

Pausa/congelamento quando a partida termina.

## Esse exercício vale como presença para a aula de hoje 01/09/2025.
