# meu-primeiro-app

Este é um projeto React Native criado com Expo para o primeiro contato com desenvolvimento mobile.

## Como rodar

1. Instale o Node.js (https://nodejs.org/)
2. Instale o Expo CLI globalmente:
   ```
npm install --global expo-cli
   ```
3. Instale o app Expo Go no seu celular:
   - [Google Play (Android)](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - [App Store (iOS)](https://apps.apple.com/app/expo-go/id982107779)
4. No terminal, execute:
   ```
npx expo start
   ```
5. Escaneie o QR Code com o Expo Go para rodar o app no celular.
